Necesitaria crear una aplicación, la cual se llamara Deamonize, para analizar servicios de Windows y clasificarlos como Seguros, Sospechosos o Peligrosos mediante:

1. Recolección precisa de datos de servicios (más allá del nombre de visualización). Que posea una base de datos de servicios seguros, sospechosos o Peligrosos
2. Motor de reglas local (listas blancas/negras)
3. Consulta externa escalonada (VirusTotal → Búsqueda web → IA). Esta consulta actualizaria la base de datos interna que el software ya tendria sobre peligrosos, seguros o sospechosos
4. Sistema de caché local. 
5. Características extra: heurísticas de ubicación, detección de suplantación, reportes
6. Para los servicios detectados como seguros o peligrosos, incluir algun link o referencia de donde se obtuvo la informacion.
7. Hacer un relevamiento de las aplicaciones que ya existen que realizan lo mismo o parecido a lo que quiero armar y en base a eso, sugerir cualquier añadido que sea util, novedoso o que agregue valor y funcionalidad a la aplicacion es bienvenido. Quiero que sea una aplicacion completa y util.
